# MixLab — моделирование процесса приготовления ЛКМ

Интерактивное учебное Web-приложение для лабораторной работы № 2.

## Состав проекта
- `index.html` — структура сайта и разделы лабораторной работы.
- `styles.css` — оформление и адаптивная вёрстка.
- `app.js` — математические расчёты, графики, эксперименты и оптимизация.

## Запуск локально
1. Распакуйте архив в отдельную папку.
2. Откройте `index.html` в Google Chrome, Microsoft Edge или Firefox.
3. Для построения графиков требуется подключение к интернету, так как Chart.js загружается с CDN.

## Математическая модель
По методическим указаниям:
- `G = G1 + G2`
- `Pi = (G1*C1 + G2*C2) / (G1 + G2)`
- `T = V / G`
- `C(t) = C0 * exp(-t/T) + Pi * (1 - exp(-t/T))`

Для интерактивного исследования скорости мешалки используется отдельное учебное допущение:
`T_eff = T * (300 / n) / k`, где `n` — скорость вращения, `k` — коэффициент интенсивности.
Степень однородности оценивается как `H = 100 * (1 - exp(-t/T_eff))`.

Критерий условных энергозатрат:
`E = V * (n / 300)^2 * t`.
Оптимизатор перебирает скорости 100–500 об/мин с шагом 10 и выбирает режим с минимальным E при H не ниже заданной и времени 1–20 минут.

**Важно:** зависимость `T_eff` от скорости, показатель однородности `H` и критерий `E` являются учебными инженерными допущениями для выполнения функциональных требований задания. В исходном документе базовая модель задаёт `T=V/G` и динамику концентрации, но не содержит отдельной формулы для скорости вращения или энергозатрат. Это нужно понимать и проговорить при защите.

## Размещение на GitHub Pages
1. Создайте аккаунт на https://github.com/ (если его ещё нет).
2. Создайте новый публичный репозиторий, например `mixlab-lkm`.
3. Загрузите в корень репозитория файлы `index.html`, `styles.css`, `app.js` и `README.md`.
4. Откройте **Settings → Pages**.
5. В блоке **Build and deployment** выберите **Deploy from a branch**.
6. В качестве Branch выберите `main`, папку `/ (root)`, нажмите **Save**.
7. Через некоторое время GitHub покажет ссылку вида `https://ВАШ-ЛОГИН.github.io/mixlab-lkm/`.

## Что показать на защите
1. Перейти по разделам сайта: теория, модель, расчёт, оптимизация, результаты.
2. Поменять скорость, время, объём и коэффициент интенсивности — метрики и графики обновятся.
3. Пояснить материальный баланс и формулу концентрации.
4. Запустить оптимизацию и показать найденный режим.
5. Скачать CSV с результатами семи расчётных режимов.

## Перед сдачей
- Проверьте сайт в браузере.
- Убедитесь, что графики загрузились.
- Разместите проект на GitHub Pages и откройте публичную ссылку в режиме инкогнито.
- В письме преподавателю укажите ссылку и приложите ZIP с исходным кодом.
